# RESTful API (v1)

Хаяг: `/api/v1`. Хариу бүр JSON. Нэвтэрсний дараа `Authorization: Bearer <token>` толгойг илгээнэ. Токен 30 хоног хүчинтэй бөгөөд нууц үг солиход хүчингүй болно.

## Нэвтрэх

```http
POST /api/v1/login
{ "email": "...", "password": "...", "device_name": "phone" }
```

## Нийтийн

| Арга | Зам | Тайлбар |
|---|---|---|
| GET | `/courses?q=&category=` | Нийтэлсэн сургалтууд |
| GET | `/courses/{slug}` | Сургалт, хичээл, шалгалтын жагсаалт |

## Нэвтэрсэн хэрэглэгч

| Арга | Зам | Тайлбар |
|---|---|---|
| GET | `/me` | Өөрийн мэдээлэл |
| POST | `/logout` | Токен цуцлах |
| GET | `/lessons/{id}` | Хичээл. Байхгүй файлын хаяг `null` |
| GET | `/media/{id}` | Видео, аудио, хадмал файл |

## Суралцагч

| Арга | Зам | Тайлбар |
|---|---|---|
| GET | `/my-courses` | Эхэлсэн сургалт, дуусгалтын хувь |
| POST | `/lessons/{id}/progress` | `position`, `duration`, `ended` |
| GET | `/bookmarks` | Хадгалсан хичээл |
| POST | `/lessons/{id}/bookmark` | Хадгалах, хасах |
| GET | `/quizzes/{id}` | Асуултууд, зөв хариултгүй |
| POST | `/quizzes/{id}/submit` | `answers: { асуултын_id: сонголтын_индекс }` |
| GET | `/quiz-results` | Өөрийн дүн |
| GET, PUT | `/settings` | Хүртээмжийн тохиргоо |
| GET, POST | `/feedback` | Санал хүсэлт |

## Админ

| Арга | Зам | Тайлбар |
|---|---|---|
| GET | `/admin/stats` | Системийн статистик |
| GET | `/admin/users` | Хэрэглэгчид |

## Алдаа

| Код | Утга |
|---|---|
| 401 | Токен байхгүй эсвэл хүчингүй |
| 403 | Эрхгүй эсвэл бүртгэл идэвхгүй |
| 404 | Олдсонгүй эсвэл нийтлэгдээгүй |
| 422 | Өгөгдөл буруу, `errors` талбарт тайлбар |
| 429 | Хэт олон хүсэлт (минутад 120, нэвтрэх 10) |

Контент (сургалт, хичээл) удирдах API байхгүй: админ үүнийг вэбээс хийнэ.
