# Дэлгэц уншигчийн гар туршилтын заавар

Автомат шалгалт (axe, accessibility tree) нь кодын алдааг олдог ч хүн сонсоход ойлгомжтой эсэхийг хэлж чадахгүй. Энэ туршилтыг бодит дэлгэц уншигчаар, хулгана ашиглалгүй хийнэ.

## Бэлтгэл

1. NVDA суулгана: https://www.nvaccess.org/download/
2. Windows тохиргооны **Time & language → Language & region** хэсгээс Япон хэл нэмж, яриа (Speech) багцыг суулгана. Монгол дуу хоолой суулгах боломжтой эсэхийг шалгана.
3. NVDA-ийн **Preferences → Settings → Speech** хэсэгт **Automatic language switching** сонголтыг асаана.
4. Системийн **Хүртээмжийн тохиргоо**-ноос "Хуудсыг дуугаар унших самбар"-ыг унтраана: NVDA-тай зэрэг дуугарахгүй.
5. `php artisan serve` ажиллуулж, Chrome, Edge эсвэл Firefox-оор `http://127.0.0.1:8000` хаягийг нээнэ.

## NVDA-ийн гол товчлуур

| Товч | Үйлдэл |
|---|---|
| H | Дараагийн гарчиг |
| D | Дараагийн хэсэг (landmark) |
| K | Дараагийн холбоос |
| B | Дараагийн товчлуур |
| F | Дараагийн form-ын талбар |
| T | Дараагийн хүснэгт |
| Ctrl + Alt + сум | Хүснэгтийн нүдээр шилжих |
| NVDA + F7 | Гарчиг, холбоосын жагсаалт |
| NVDA + Space | Хуудас унших, form бөглөх горим солих |

## Шалгах хуудас бүрт

- Гарчиг нь хуудсыг зөв нэрлэж байна уу?
- Эхний Tab "Үндсэн агуулга руу шилжих" холбоос руу очиж байна уу?
- H товчоор хуудасны бүтцийг ойлгож болж байна уу?
- Товчлуур бүрийн нэр юу хийхийг хэлж байна уу?
- Focus хаана байгаа нь ойлгомжтой, гацахгүй байна уу?

## Анхаарах эрсдэлүүд

- **Монгол кирилл:** NVDA-д Монгол дуу хоолой байхгүй бол Монгол текстийг өөр хэлний дүрмээр буруу дуудаж болно. Энэ нь сайтын бус, суулгасан дуу хоолойн асуудал.
- **Хэл солигдох:** 10-р алхамд Япон үсэг уншигдахгүй бол 2, 3-р бэлтгэлийг шалгана.
- **Өөрийн уншигч:** Самбарыг асаасан үед NVDA-г түр зогсоож шалгана (NVDA + Q).

## Алдаа мэдээлэх

Алдаа бүрд дараахыг бичнэ: хуудасны хаяг, алхам, NVDA юу гэж хэлсэн, юу гэж хэлэх ёстой байсан, хөтчийн нэр.

Дараа нь JAWS, Narrator, VoiceOver, TalkBack-аар мөн адил давтах нь зүйтэй. Бодит хэрэглэгчид буюу харааны бэрхшээлтэй хүмүүсээр туршуулах нь хамгийн найдвартай.
